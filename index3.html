SMART STORAGE OPTIMIZER FOR ANDROID DEVICES

Project ID: 2427030186

Problem Statement

Modern Android devices face storage inefficiency due to large unused files, duplicate media, and poor cloud utilization. Users often struggle to manually identify redundant data. This project proposes an intelligent storage optimization system that analyzes file metadata, detects duplicates using hash values, filters large and unused files, and recommends optimized cloud storage allocation.

Literature Review

Existing storage management solutions such as built-in Android storage analyzers and third-party cleaning applications focus mainly on identifying large files and clearing cache. Cloud storage platforms like Google Drive, OneDrive, and Dropbox provide backup solutions but do not intelligently decide which files should be offloaded based on usage patterns and duplication. Previous research in storage optimization emphasizes file compression, manual backup, and cache cleaning. However, most systems require user intervention and do not integrate intelligent decision-making for automatic cloud selection based on available storage capacity.

Research Gap / Innovation

Although many storage cleaning applications exist, they lack intelligent analysis of user file behavior and do not provide optimized cloud allocation recommendations. Research Gap:
  • No combined system for duplicate detection + usage-based filtering
  • Lack of smart cloud selection based on available storage
  • Limited automation in file optimization decision-making
Innovation in This Project:
  • Hash-based duplicate file detection
  • Usage-time analysis for identifying unused files
  • Size-based intelligent filtering
  • Cloud storage recommendation engine
  • Fully automated optimization workflow

Dataset / Input Source

Source: Simulated Android storage metadata generated using Python.
  • File Name
  • File Size (MB)
  • File Type
  • Last Accessed Time
  • Hash Values (Duplicate Detection)
Preprocessing:
  • Converted sizes into MB
  • Calculated unused days
  • Duplicate hash comparison

Result & Analysis

The proposed Smart Storage Optimizer was tested using a simulated dataset of file metadata. The system successfully: Identified large files exceeding the predefined size threshold Detected duplicate files using hash value comparison Identified rarely used files based on usage duration Selected the cloud platform with maximum available free space Generated optimized file offloading recommendations The system demonstrated correct classification and decision-making based on defined rules. Analysis The analysis shows that rule-based filtering combined with metadata evaluation can effectively optimize storage management. By integrating duplicate detection, usage frequency analysis, and cloud selection, the system reduces unnecessary manual effort. The results indicate that: Storage optimization decisions can be automated Duplicate and large files significantly contribute to storage usage Intelligent cloud selection improves storage distribution efficiency Although the current implementation uses a simulated dataset, the model can be scaled for real-world deployment with actual device storage data.
